# Бот-тренажёр по философии (300 вопросов)

Telegram-бот для подготовки к тесту по философии (ТГЭУ) по опроснику из 300 вопросов
(история философии, онтология, гносеология, логика, этика и эстетика, общество,
глобальные проблемы, ИИ, противодействие коррупции, Конституция и стратегия «Узбекистан-2030»).

К каждому вопросу 4 варианта ответа, один правильный. Порядок вариантов при каждом показе перемешивается.

## Режимы

- 🎲 **Случайные 25 / 50**: случайная выборка, как на экзамене
- 📚 **Блоки по 25**: вопросы 1–25, 26–50, … 276–300
- 📝 **Все 300** по порядку или 🔀 вперемешку
- ❌ **Работа над ошибками**: вопросы, на которые вы ответили неверно. Вопрос уходит из списка, когда вы ответите на него правильно
- 📊 **Статистика**: число ответов, процент правильных, завершённые тесты

После каждого ответа бот показывает правильный вариант, в конце теста ставит оценку
(≥90% — 5, ≥70% — 4, ≥60% — 3).

Команды: `/start`, `/menu`, `/stop`, `/stats`, `/reset`.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости и запустите бота:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN
python -m bot.main
```

## Веб-версия

`web/index.html` — тот же тест в виде одной веб-страницы, без сервера: режимы, ключ с ответами, статистика
в браузере. Её собирает из `data/` скрипт `python tools/build_web.py`; после правки вопросов его надо перезапустить.

## Бесплатный хостинг на Render (можно с телефона)

В репозитории есть `render.yaml`. На Render бот сам переключается в режим webhook.

1. Получите токен бота у @BotFather.
2. Зайдите на [render.com](https://render.com) и войдите через GitHub.
3. **New → Blueprint**, выберите репозиторий `jlifeisgood/red`, вставьте `BOT_TOKEN`, нажмите **Deploy**.
4. Чтобы бот не засыпал, на [cron-job.org](https://cron-job.org) создайте задание: каждые 10 минут открывать
   `https://<имя-сервиса>.onrender.com/health`.

Без такого «пинга» бесплатный сервис засыпает через 15 минут простоя. Первое сообщение
после этого бот обработает примерно через минуту, а статистика обнулится. Статистика также
сбрасывается при каждом новом деплое, потому что диск на бесплатном тарифе не сохраняется.

## Постоянная работа на сервере (Linux + systemd)

```bash
sudo apt install -y python3 python3-venv git
sudo useradd -r -m -d /opt/philosophy-bot bot
sudo -u bot git clone -b ccr-141880db-zbygkk https://github.com/jlifeisgood/red.git /opt/philosophy-bot
cd /opt/philosophy-bot
sudo -u bot python3 -m venv .venv
sudo -u bot .venv/bin/pip install -r requirements.txt
sudo -u bot cp .env.example .env    # впишите BOT_TOKEN, DB_PATH=/opt/philosophy-bot/bot.db
sudo cp deploy/philosophy-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now philosophy-bot
```

Бот запускается вместе с сервером и перезапускается после падения.

- статус: `systemctl status philosophy-bot`
- логи: `journalctl -u philosophy-bot -f`
- обновление: `cd /opt/philosophy-bot && sudo -u bot git pull && sudo systemctl restart philosophy-bot`

С одним токеном может работать только один экземпляр бота. Если бот запущен ещё где-то, например на вашем компьютере, его нужно остановить.

## Вопросы

Вопросы лежат в `data/questions_*.txt` в простом текстовом формате:

```
51. Какой закон действует в данном рассуждении?
Все рыбы дышат жабрами. Осетр – рыба. Следовательно, осетр дышит жабрами.
+ Закон достаточного основания
- Закон исключённого третьего
- Закон отрицания отрицания
- Закон единства и борьбы противоположностей
```

`+` отмечает правильный ответ, `-` неверные. Эти файлы заодно служат ключом с ответами.
Чтобы исправить ответ или добавить вопрос, отредактируйте файл и перезапустите бота.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Тесты проверяют, что на месте все 300 вопросов, у каждого 4 разных варианта и ровно один правильный,
а также логику подсчёта баллов, оценок и работы над ошибками.
