# Башня

Пошаговая игра на выживание (HTML/JS) в обёртке Capacitor для Android.
100 этажей, по 3 комнаты на этаже, лифты, убежище, прицельный бой, навыки, концовки.

## Запуск в браузере
Откройте `www/index.html`.

## Механики
- **Энергия** — шаги: каждая дверь и подъём тратят её, на нуле теряешь здоровье.
- **Этаж:** 3 двери (подсказки бывают ложными) и лифт. Лифт исправен, сломан (чинится материалами) или обходится по тросу.
- **Убежище:** вниз на исправном лифте. Сон, кухня (блюда), верстак; верстак и кухню можно улучшать.
- **Бой:** удары по голове, корпусу, рукам и ногам; у врагов особенности (броня, яд, регенерация, шипы и т. д.).
- **Развитие:** навыки (у каждого оружия свой), перки при повышении уровня, стартовые перки, три уровня сложности.
- **Мир:** запертые комнаты и ключи, автоматы, торговцы, события, задания по телефону.
- **Мета:** достижения, четыре концовки, «Новая игра+».

## Сборка APK
Нужны Node 18+, JDK 21 и Android SDK.

    npm install
    npm run apk        # debug-сборка
    # APK: android/app/build/outputs/apk/debug/app-debug.apk

Либо запушьте проект на GitHub: workflow `Build Android APK` собирает подписанный release-APK и прикладывает его как artifact `tower-release-apk`.

### Подпись
Готовый APK для установки на телефон: https://github.com/Jlifeisgood/red/releases/download/apk/tower.apk (обновляется после каждой сборки ветки `tower-game`).

Постоянный ключ берётся из секретов репозитория: `ANDROID_KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
Если секретов нет, workflow подписывает APK временным ключом: он устанавливается, но обновить приложение поверх сборки с другим ключом нельзя.
Файл ключа в репозиторий не коммитьте (папка `signing/` и `*.jks` в `.gitignore`).

Сохранение: автоматическое (localStorage). Экран «Настройки» даёт экспорт и импорт сохранения кодом, раздельные звук и вибрацию, сброс прогресса.

Графика (`src3d/`, three.js), в духе Skyhill: этаж показан в разрезе здания — комната, комната, лестничная клетка с лифтом, комната;
неизведанные комнаты тёмные, видны соседние этажи и гроза снаружи (`building.js`, мебель и отделка — `props2d.js`). Пост-обработка — `post.js`.
Персонажи — рисованные 2D-«вырезки»: части тела рисуются на canvas (`ink.js`, `human2d.js`, `quad2d.js`) и анимируются по суставам (`rig2d.js`), у каждого — тень на стене.
Игра работает в альбомной ориентации (Android: `sensorLandscape`, полноэкранный режим в `MainActivity.java`).
Камера и окно сцены общие для SVG-слоёв и WebGL (`VIEW` в `www/scene.js`). Иконки интерфейса — свои, `www/icons.js`.
После правок перегенерируйте бандл: `npm run build3d` (результат `www/chars3d.bundle.js` лежит в репозитории, CI его не пересобирает).
Если WebGL недоступен, игра автоматически показывает плоские SVG-версии персонажей.

Игровой код: `www/game.js`, графика фонов: `www/art.js`, сцена: `www/scene.js`. После правок выполните `npx cap sync android`.
