# YouTube

Claude не видит видео напрямую — «просмотр» = метаданные + транскрипт + (при необходимости) кадры.
Скрипт: `python3 .claude/skills/youtube/scripts/yt.py` (зависимость `yt-dlp` ставится автоматически через pip; для кадров нужен `ffmpeg`).

## Шаги

0. Только тема, без ссылки — найти видео:
   `python3 .claude/skills/youtube/scripts/yt.py --search "<тема>"`
   Выводит топ-5 (название | канал | длительность | URL). Выбрать подходящее (при сомнении — один вопрос пользователю), указать в ответе, какое выбрано.
1. Метаданные + транскрипт с таймкодами:
   `python3 .claude/skills/youtube/scripts/yt.py "<URL>" [--lang ru,en]`
2. Кадры (слайды, код на экране): 
   `python3 .claude/skills/youtube/scripts/yt.py "<URL>" --frames [--at 00:01:30,00:05:10] [--count 8] [--out DIR]`
   Затем открыть JPG через Read.
3. Отвечать по транскрипту, ссылаться на таймкоды. Нет субтитров — сказать об этом, опираться на описание/главы/кадры; не выдумывать.

## Заметки
- Если YouTube недоступен из среды (сетевые ограничения, 403/бот-проверка) — сообщить пользователю как есть, не обходить.
- Длинный транскрипт (>1 ч): сначала главы и описание, затем нужные участки.
- Приватные/возрастные видео требуют cookies — сообщить пользователю.
- Временные файлы — во временную папку, не в репозиторий.
